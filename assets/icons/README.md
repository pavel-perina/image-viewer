# Icons

SVG, drawn on a 24 by 24 grid, aligned to whole pixels.

* **Named by meaning, not by shape:** `zoom-in`, `search`, `go-up`, `view-refresh`, following
  the freedesktop icon naming spec where it has a name. One drawing that serves two meanings is
  one file with a second name given in the resource list.
* **Colours are placeholders**, replaced by the theme's when the icon is drawn, so that icons
  follow the palette. Pure `#ff00ff` is the main ink and `#00ffff` the second shade; any other
  colour stays as drawn.

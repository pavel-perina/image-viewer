# Rys and Tessera — icon studies 01

Original vector explorations, not an accepted application identity. The existing
identity drafts and application assets are unchanged.

[Comparison sheet](../rys-tessera-icons-01.svg) shows 96 px samples on dark and
16 / 24 / 32 px samples on light. These are scaled previews; the chosen icon will
need optical adjustments for small sizes.

| Concept | Individual SVG | Direction |
| --- | --- | --- |
| R1 · Lynx | [rys-lynx.svg](rys-lynx.svg) | Warm animal face and pointed ear tufts |
| R2 · Watchful | [rys-eye.svg](rys-eye.svg) | A lynx eye held by an open head/frame |
| R3 · Earframe | [rys-frame.svg](rys-frame.svg) | A picture inside a lynx silhouette |
| T1 · Loose tile | [tessera-loose.svg](tessera-loose.svg) | A mosaic with one rotated piece |
| T2 · Inlay | [tessera-inlay.svg](tessera-inlay.svg) | Three broad tiles forming a diagonal image |
| T3 · Tilemark | [tessera-letter.svg](tessera-letter.svg) | A T assembled from separate pieces |

All six use a 128-unit canvas. Fixed colours: slate #27343e, mint #81d8c5,
amber #f5bd66, warm white #f3f3ec and, for the mosaic concepts, blue #8ab8d6.
The app icon would retain its palette when the interface hue changes.
